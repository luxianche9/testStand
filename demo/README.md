# 演示：没有被测对象时怎么演示 testStand

两条路线可以单独用，也可以合在一段视频里：

| 路线 | 需要什么 | 演示什么 |
|---|---|---|
| **A. 虚拟被测件** | 只要这台电脑 | 通信链路、在报文上点出协议字段、变量、整页画布上位机、命令下发、AI 编排自动测试 |
| **B. 机柜自环** | 机柜里的板卡，几根短接线 | 真实硬件控制与采集：AO 出电压 AI 量回来、继电器动作 DI 读回、串口卡两口互发 |

## 准备（两条路线都要）

```powershell
cd app
pnpm install
pnpm python:setup
cd ..\devices
uv sync
uv run python pack.py comm_link   # -> devices\dist\comm_link-1.0.0.tsdev
cd ..\app
pnpm dev                        # 启动 testStand（开发模式）
```

在 testStand 里新建一个演示项目（例如 `D:\testStand-demo`），之后的设备、协议、画布都存在里面。

## 路线 A：虚拟被测件

`dut-sim/dut_sim.py` 是一个用 Python 标准库写的 TCP 服务端，像一块控制板：每 100 ms 上报一帧状态（电压、温度、LED / 风扇 / 故障位、帧计数），收到命令帧就改变状态并回应答。协议见 `dut-sim/dut_sim.icd.yaml`。

```powershell
python demo\dut-sim\dut_sim.py            # 127.0.0.1:9000，保持这个窗口开着
```

1. **加链路**：设备管理 → + → 添加设备… → 选 `devices\dist\comm_link-1.0.0.tsdev`，名称“被测板（虚拟）”。编辑这台设备，连接方式选“TCP 客户端”，地址 `127.0.0.1`，端口 `9000`，保存。`link` 字节流开始滚动。
2. **解析协议**（视频重点）：「变量」→ 这台设备的 `link` → 解析协议 → 新建 ICD → 抓取最近报文 → 点一帧，拖选第 4–5 字节（电压，小端 u16，系数 0.001，单位 V），定义为字段；同样定义温度（6–7 字节，i16，系数 0.1）。也可以直接把 `dut_sim.icd.yaml` 复制到项目的 `icd\` 目录，选它绑定，别名 `dut`。
3. **搭画布**：运行监控 → 编辑布局，把变量 `dut.status.voltage`、`dut.status.temp` 拖到空白处（变成大数字），再拖一个示波器放电压；`led` / `fan` / `fault` 拖进来是指示灯。
4. **发命令**：从「组件」拖“按钮”，设置动作为这台设备的 `write_hex`，固定参数 `hex` 填下表的帧。点“开灯”，指示灯亮、温度慢慢升；“设 1.5 V”后电压曲线下降。

   | 动作 | hex |
   |---|---|
   | 开灯 / 关灯 | `AA 55 02 10 01 1C 00` / `AA 55 02 10 00 DD C0` |
   | 开风扇 / 关风扇 | `AA 55 02 11 01 1D 90` / `AA 55 02 11 00 DC 50` |
   | 注入故障 / 清除故障 | `AA 55 02 13 01 1C F0` / `AA 55 02 13 00 DD 30` |
   | 电压目标 1.5 V / 3.0 V | `AA 55 03 12 DC 05 38 A6` / `AA 55 03 12 B8 0B 93 A2` |

5. **AI 自动测试**：对 AI 助手说：“给被测板写一个测试：用 ICD 编码器 set_voltage 依次设 1000、2000、3000 mV，每档等 2 秒，检查 dut.status.voltage 的平均值误差小于 5%；再 set_led 开灯，检查 led 位为 1；最后注入故障，检查 voltage 掉到 0.1 V 以下，然后清除故障。”确认后运行，看画布跳动、结果表、事件时间轴；打开运行历史回放。
6. **演示一次失败**：把某档允许误差改成 0.1%，再运行，展示 Fail 和回放里的取证。

## 路线 B：机柜自环

先确认机柜上**没有接任何被测对象**，再按板卡手册的针脚表接短接线（下面只是思路，针脚号以手册和 testStand 的设备信息为准）：

| 输出 | 接到 | 演示 |
|---|---|---|
| AO 一路（如 PCI-6208V CH0） | AI 一路（如 PCI-1710L AI0），地线相连 | 滑块设 AO 电压，大数字和示波器显示 AI 量到的值；测试里扫 0–5 V 判误差 |
| 继电器一路（如 PCI-1762 K0）常开触点 | DI 一路 + 电源 / 地（按 DI 输入要求） | 开关控制继电器，指示灯显示 DI 读回 |
| 串口卡 P1 | 串口卡 P2（交叉线） | 一口发、一口收，在终端和总线跟踪里看 |

AO 的电压范围在测试和滑块里设上下限，不要超过 AI 量程。
