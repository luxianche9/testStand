# 运行监控重做方案：多窗口、组件化的监控工作台

> 2026-10-12。P1～P4 已实现（见第 9 节）。依据：对开源监控 / 可视化 / 总线 / HMI 软件的调研（第 1 节），以及当前运行监控的问题（第 0 节）。

## 0. 现状的问题

| 问题 | 表现 |
|---|---|
| 布局固定 | 示波器在上、终端/结果在下，只有一个分隔条；看多种数据只能挤在一个示波器里 |
| 组件种类少 | 只有示波器（含数字量面板）和终端；总线报文、寄存器/状态字、数值表、仪表都没有专门的视图 |
| 手动控制不直观 | 控制在设备卡片的“控制”菜单里，弹出通用 JSON 表单：通道号、电压都要手打，继电器要填 `[0,5,40]` 这样的数组；控制和看结果在两个地方 |
| 字体偏大、密度低 | 正文 13px，大量 24～32px 行高，一屏能看的通道和报文少 |

## 2. 总体形态

把“运行监控”改成一个**监控工作台**：dockview 承载若干**面板**，每个面板是一个组件，订阅一条或多条流；布局随项目保存。

- **左：数据源树**（设备 → 流，ICD 派生字段也在这里），每条流显示类型图标和当前值；拖到工作区任意位置生成合适的面板，或拖进已有面板加一路。
- **中：dockview 工作区**。面板可拆分、成组为标签页、浮动，或**弹出到独立窗口**拖到第二块屏幕（Electron 允许子窗口，同一 JS 上下文共享实时订阅）。
- **右：属性栏**（Rerun 的 Selection 面板）：选中面板或通道时显示它的配置——颜色、单位、告警限、显示方式、统计——面板本身不放配置表单，保持干净。
- **下：全局时间轴**：实时 / 回放切换，运行的区域、步骤、判定、调用都在这一条上；**所有面板共享时间光标和时间范围**（CANoe 的 Trace 与 Graphics 联动）：在示波器上点一个时刻，总线跟踪滚到那一帧，数字量面板显示那一刻的状态。

## 3. 组件目录（按流类型）

| 面板 | 适用流 | 要点 | 参照 |
|---|---|---|---|
| **示波器** | scalar、block、ICD 数值字段 | 叠加 / 分轨（stacked）两种；现有前面板（时基、V/div、自动设置、RUN/STOP）保留；**选区统计** min/max/mean/rms/pp；双光标测 Δt、ΔV；告警限画成虚线 | Open MCT 叠加/堆叠图，CANoe Graphics |
| **XY 图** | 两路 scalar | 一路作 X、一路作 Y（如 LVDT A/B） | PlotJuggler 右键拖 |
| **数值表** | 多路 scalar / ICD 字段 | 每行：名称、当前值、单位、min/max/mean、迷你曲线、越限着色；等宽数字 | CANoe Data 窗口，Grafana Stat |
| **仪表** | 单路 scalar | 圆表 / 条形 / 大数字三种外观，带告警分段 | Serial Studio、FUXA、Grafana Gauge |
| **数字量** | bits（DI/DO） | 每位指示灯，8 位一组，位名；DO 可点击切换（第 4 节） | 现有数字量面板，Phoebus LED |
| **继电器矩阵** | bits（`display: switches`） | 触点图形，按连接器/分组排布；点击切换；显示闭合路数、动作计数 | — |
| **状态时间线** | bits、枚举 ICD 字段 | 每位或每个状态一行，按时间画色块（替代 48 条逻辑线） | Grafana State timeline，Rerun 状态行 |
| **状态字 / 寄存器** | bits（`display: code`）、ICD 位域 | 十六进制 + 二进制按位格，位域分段着色并标注名称和值（如 `MODE=2 RUN FAULT=0`）；**变化的位高亮** | SavvyCAN 字节/位变化高亮 |
| **串口终端** | bytes | 文本 / HEX / 混合；RX/TX 不同颜色；时间戳（绝对/相对/Δ）；行结束、编码；底部**发送栏**（历史、预置命令、HEX 模式、追加 CR/LF）；虚拟滚动 | Serial Studio 终端，常见串口助手 |
| **总线跟踪** | frames、bytes 切帧后 | **按时间滚动 / 固定位置（每 ID 一行原地刷新，显示计数和周期）**；每列过滤；按 ICD 解码列；字节变化高亮；标记 | CANoe Trace，SavvyCAN |
| **报文详情** | 选中的一帧 | 字段树：原始字节 ↔ 字段对应高亮、换算值、校验结果 | Foxglove Raw Messages，PulseView 注释行 |
| **结果表 / 运行控制台** | 运行 | 现有结果表、步骤与调用控制台改成面板 | — |
| **控制面板** | 设备工具 | 第 4 节 | CANoe Panel Designer，FUXA |

自动布局（Rerun 的启发式）：项目第一次打开或用户点“按数据生成布局”时，按流类型生成默认布局——模拟量进一个示波器，宽位流进数字量/继电器矩阵，串口进终端，总线进跟踪，ICD 字段进数值表。用户改过之后以用户布局为准。

## 4. 手动控制：从“填表单”改为“直接操作”

### 4.1 三条路径

1. **在显示部件上直接操作**（最常用）：DO 指示灯点一下切换；继电器矩阵点触点切换；示波器/数值表里 AO 设定值那一行拖滑块；串口终端底部直接输入发送。显示和控制在同一处，结果立刻在同一处看到。
2. **控制面板**：用户从设备工具列表拖一个工具进控制面板，**固定一部分参数**（如通道 3），生成一个控件——按钮、开关、滑块、旋钮、预置值按钮组——保存在布局里，下次直接点（CANoe Panel Designer / FUXA 的做法）。适合“台架上常用的几个动作”。
3. **工具对话框**（兜底）：仍可从设备“控制”菜单调用任意工具，但表单本身换成第 4.2 节的控件，不再手打。

### 4.2 按参数 schema 自动选控件（不需要插件额外声明）

| 参数特征 | 控件 |
|---|---|
| 整数、有 min/max、名字是 channel / line / relay / port | **通道选择器**：按插件 pinout 的 `channelKind`/`channelIndex` 列出“AO0 · CON1-50”这样的按钮格或下拉，可搜索；不再输入数字 |
| 浮点、有 min/max | **滑块 + 拖动改数字**（拖动、滚轮、方向键；Shift 精调、Ctrl 粗调）+ 单位 + 预置芯片（0、安全值、min、max、最近使用） |
| 布尔 | 开关（显示含义，如“闭合 COM-NO / 释放 COM-NC”，取自参数说明） |
| 枚举 / Literal | 分段按钮（≤ 5 项）或下拉 |
| 通道列表 `list[int]` | 多选按钮格（继电器、DO），支持框选、全选、反选 |
| 位掩码整数 | 位格开关，实时显示十六进制 |
| 十六进制字符串 | HEX 输入：按字节分组、非法字符即时标红、显示字节数；可切换“文本” |
| 文本 | 单行输入 + 历史 |

插件可以选择性地给参数加 UI 提示（JSON Schema 扩展字段，如 `x-teststand-widget: "knob"`、`"step": 0.001`），没有就按上表推断。

### 4.3 安全

- 每个控件标明工具种类（动作 / 配置 / 安全），**动作类**控件用醒目色；滑块默认“松手才发送”，可选“拖动时发送（限速 10 Hz）”。
- **测试自动运行时不能手动控制**（沿用原设计：`ExecutionCoordinator` 让一次运行占用它用到的设备，手动调用返回冲突）：运行期间相关控件全部禁用并显示“测试运行中”，运行结束自动恢复。不另设控制锁。
- 每次调用写进控制台（带 `operationId`、参数、结果），失败就地显示错误；结果未知的动作不重试。
- 工作区常驻“全部安全状态”按钮（调用各设备 `safe_state`），需二次确认。

## 6. 技术选型与数据模型

- **dockview-react**：面板、标签组、浮动、弹出窗口、`toJSON` 序列化；用自己的 CSS 变量做主题，和现有 tokens 对齐。Electron 主进程需放行 dockview 的弹出窗口（`setWindowOpenHandler`），弹出窗口与主窗口共享同一个实时订阅。
- 绘图继续用 **uPlot**（已在用，性能足够）；终端、跟踪、数值表用 **@tanstack/react-virtual** 虚拟滚动，十万行不卡。
- 拖动改数字、旋钮自写小组件（参照 draggable-number-input / react-knob-headless 的交互），不引入大依赖。
- 布局**每个项目单独保存**，随项目文件。项目文件 **v8**：`monitor` 从 `channels[]` 改为

  ```jsonc
  {"layout": { /* dockview toJSON */ },
   "panels": {"p1": {"type": "scope", "sources": [{"hardwareId": "...", "streamId": "ai0"}],
                     "settings": {"timeDivMs": 1000, "vertical": "auto"}},
              "p7": {"type": "control", "controls": [{"tool": "da6401_write_voltage",
                     "fixed": {"channel": 0}, "widget": "slider", "presets": [0, 1.65, 3.3]}]}}}
  ```

  v7 及更早的项目不再打开（不做迁移）。
- Agent **可以构建监控和控制面板**：`get_monitor` 读取布局与面板；`update_monitor` 以增量操作修改——加面板（类型、标题、位置：右侧/下方/标签到某面板）、给面板加减流、改面板设置、往控制面板加控件（工具、固定参数、控件类型、预置值）、删面板。修改进项目未保存缓冲，与人工修改同等，界面实时可见；运行前的一致性检查改成“流程用到的流都在某个面板上”。
