![alt text](docs/images/image.png)

项目功能
+ 为AI Agent提供能力+上下文
    + 能力
        + 将硬件测试资源封装成mcp中的工具调用
        + 提供编排引擎工具, 可以稳定执行有复杂时序的测试任务
        + 人在回路改变物理硬件接线, 对操作者知识水平要求最低化
    + 上下文
        + 远程电脑的登陆凭证
        + 硬件的端口和针脚信息
        + 硬件之间的拓扑连接关系
        + 日志系统

1. 逆向光纤协议板卡
2. 测试电路板功能
